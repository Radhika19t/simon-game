# Simon Game 🎮

An interactive memory-based game built using **HTML, CSS, and JavaScript**.

## 🚀 Features
- Increasing difficulty levels
- Color & sound based pattern memory
- Keyboard-based start & restart
- Responsive UI

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 📸 Preview
Press any key to start and repeat the color sequence correctly!

## 📌 How to Run
1. Clone the repository
2. Open `index.html` in your browser
